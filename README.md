# Ledger Plus

本分支：`Plus`

Ledger Plus 是项目的工作区增强分支，重点围绕文件列表、重复文件结果、删除动作和批量工具做功能增强。它适合验证“工作空间浏览器”里的高频操作，不承担正式 Release 发布职责。

## 分支定位

`Plus` 适合用于验证工作区操作体验。

- 强化重复文件扫描和结果处理。
- 增强文件删除动作，减少“只能在查重场景删除”的限制。
- 优化批量工具和底部布局空间。
- 保持依赖和运行方式轻量。
- 不包含 Max 的 Windows Release workflow。
- 不包含 Max_Mac 的 macOS DMG workflow。

正式 Windows 发布请使用 `Max` 分支。macOS DMG 请使用 `Max_Mac` 分支。

## 分支关系

| 分支 | 定位 | 适合场景 |
|---|---|---|
| `master` | 基础开源版 | 学习、轻量使用、最小功能集 |
| `Plus` | 增强工作区版 | 重复文件、删除、批量工具和布局验证 |
| `pro` | 安全事务版 | 安全边界、事务、备份、性能修复 |
| `Max` | Windows 旗舰发布版 | Windows zip / 安装器 / Release |
| `Max_Mac` | macOS DMG 分支 | macOS `.app` / `.dmg` 自动构建 |

## 核心功能

- 工作空间标准目录自动初始化。
- 收集箱文件整理与重命名。
- 标签字典、自定义标签和筛选。
- SQLite 元数据记录与搜索。
- 桌面文件导入收集箱。
- 备份状态记录和 3-2-1 备份健康度展示。
- 工作空间文件列表、文件详情和路径操作。
- 重复文件扫描与结果列表。
- 重复文件多选处理。
- 文件删除动作与查重结果解耦。
- 工作区布局空间优化。

## Plus 重点增强

该分支近期主要围绕工作区操作做增强：

- 统一文件删除逻辑。
- 修复移动操作目标冲突处理。
- 增加重复文件删除工具。
- 启用重复列表多选。
- 删除冗余的重复文件删除入口。
- 让文件删除不再依赖重复文件检测状态。
- 调整工作区下方布局空间，使操作区更宽松。

## 快速运行

环境要求：

- Python 3.10+
- Windows 10 / 11 64-bit

安装依赖：

```powershell
pip install PySide6 watchdog
```

启动程序：

```powershell
python main.py
```

首次启动会自动创建默认工作空间目录。

## 推荐验证流程

1. 使用测试工作空间，不要直接操作真实资料库。
2. 放入几组同名、同大小或内容重复的文件。
3. 扫描重复文件，验证列表展示和多选。
4. 测试删除重复项、删除普通文件和刷新列表。
5. 测试批量移动和目标文件冲突。
6. 验证删除后数据库记录、文件列表和磁盘状态一致。

## 数据与配置

- `.config.json`：本地配置文件。
- `Workspace/`：默认工作空间。
- SQLite 数据库：保存文件路径、标签、备注和备份状态。

这些文件都属于本地运行数据，不建议提交到 Git。
