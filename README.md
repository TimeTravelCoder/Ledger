# 电脑文档分类与管理软件

一款基于 PySide6 的本地桌面文件分类管理工具，支持工作空间目录、收集箱整理、标签筛选、SQLite 元数据管理、备份状态跟踪和 3-2-1 备份健康度查看。

## 功能

- 工作空间标准目录自动初始化
- 收集箱文件智能整理与重命名
- 标签字典自定义与筛选
- 文件备注、标签、状态元数据管理
- 本地 SQLite 数据同步与搜索
- 桌面文件导入收集箱
- 硬盘 / 云盘备份记录与健康度统计

## 运行

```bash
python main.py
```

## 依赖

- Python 3.10+
- PySide6
- watchdog

## 说明

- 首次启动会自动创建工作空间目录。
- 标签输入支持带 `#` 或不带 `#`。
- `.config.json` 和 `Workspace/` 属于本地运行数据，不建议提交到仓库。
